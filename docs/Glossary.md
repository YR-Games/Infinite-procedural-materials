# Глоссарий терминов и элементов РПМ

## Концептуальный уровень

1. «Параметр» – 

   1. Параметр – обозначает непустое конечное множество названий параметров функций и настраиваемых характеристик узлов материала.

   2. Тип параметра – функция, сопоставляющая параметру один из типов данных языка шейдеров (см. вспомогательный термин «типы»): скаляр, вектор или матрица определённой размерности.

   3. Диапазон значений параметра – обозначает функцию, сопоставляющую параметру множество допустимых значений, которые может принимать параметр при настройке материала.

   > (∀ p ∈ параметры) диапазон значений параметра(p) – подмножество множества значений, допустимого для типа параметра(p) Диапазон значений параметра должен быть согласован с его типом.

2. «Функция» – 

   1. Функция – обозначает непустое конечное множество переиспользуемых программных функций, из композиции которых строятся функции базовых текстур, функции смешивания и функции модификаторов.

   2. Код – обозначает код на шейдерном языке, соответствующий грамматике из приложения А.

   3. Код функции: функции → код

   4. Вход функции: функции → {} параметры

   5. Выход функции: функции → типы

   6. Функции шейдерного языка, используемые функцией – обозначает непустое множество встроенных функций языка шейдеров, из композиции которых построена данная функция.

   7. Функции шейдерного языка – обозначает непустое конечное множество встроенных (примитивных) функций языка шейдеров GLSL (математических, тригонометрических, геометрических и других), которые не раскладываются на более простые составляющие в рамках данной модели предметной области.

   8. Вход функции шейдерного языка: функции шейдерного языка → {}
параметры

   9. Выход функции шейдерного языка: функции шейдерного языка → типы

3. «Базовая текстура» – 

   1. Базовые текстуры – обозначает непустое конечное множество экземпляров базовых текстур – узлов, генерирующих исходный узор, к которому в дальнейшем применяются модификаторы и смешивание слоёв.

   2. Параметры базовой текстуры – обозначает функцию, сопоставляющую экземпляру базовой текстуры конечное, возможно пустое, множество параметров, значения которых пользователь может изменять для настройки внешнего вида узора.

   3. Функции базовых текстур – обозначает непустое конечное множество названий программных функций, каждая из которых реализует алгоритм генерации одного вида базового узора.

   4. Название функции базовой текстуры: функции базовых текстур →
название

   5. Код функции базовой текстуры: функции базовых текстур → код

   6. Вход функции базовой текстуры: функции базовых текстур → {}параметры

   7. Выход функции базовой текстуры: функции базовых текстур → типы

      > Термины «название», «код», «вход» и «выход» функции базовой текстуры обозначают соответственно её имя, текст исходного кода, множество формальных параметров и тип возвращаемого значения.

   8. Реализация базовой текстуры – обозначает функцию, сопоставляющую каждому экземпляру базовой текстуры одну функцию базовой текстуры, вычисляющую его значение.

   9. Функции, используемые функцией базовой текстуры – обозначает непустое множество функций, из композиции которых построена данная функция базовой текстуры.

4. «Режим смешивания»  – 

   1. Режимы смешивания – обозначает непустое конечное множество названий способов объединения цвета слоя со значением, накопленным предыдущими слоями канала.

   2. Функции смешивания – обозначает непустое конечное множество программных функций, каждая из которых реализует один из режимов смешивания.

   3. Название функции смешивания: функции смешивания → название

   4. Код функции смешивания: функции смешивания → код

   5. Вход функции смешивания: функции смешивания → {}параметры

   6. Выход функции смешивания: функции смешивания → типы

      > Термины «название», «код», «вход» и «выход» функции смешивания имеют смысл, аналогичный одноимённым терминам модуля 3.

   7. Реализация режима смешивания – функция, сопоставляющая каждому режиму смешивания ровно одну функцию смешивания, вычисляющую его значение (отношение «реализуется» на диаграмме).

   8. Функции, используемые функцией смешивания – обозначает непустое множество функций, из композиции которых построена данная функция смешивания.

5. «Модификатор» – 

   1. Модификаторы – обозначает непустое конечное множество названий модификаторов – операций преобразования результата базовой текстуры, например изменение диапазона значений, инверсия, цветокоррекция и т.д..

   2. Параметры модификатора: модификаторы → {}параметры

   3. Функции модификаторов – обозначает непустое конечное множество программных функций, каждая из которых реализует один вид модификатора.

   4. Код функции модификатора: функции модификаторов → код

   5. Вход функции модификатора: функции модификаторов → {} параметры

   6. Выход функции модификатора: функции модификаторов → типы

   7. Реализация модификатора – функция, сопоставляющая каждому модификатору ровно одну функцию модификатора, вычисляющую его значение (отношение «реализуется» на диаграмме).

   8. Функции, используемые функцией модификатора – обозначает непустое множество функций (см. Модуль 7), из композиции которых построена данная функция модификатора (отношение «использует» на диаграмме).

   > (∀ l ∈ слои) (∀ i ∈ I[2, length(модификаторы слоя(l))]) значение, вычисленное функцией модификатора для el(модификаторы слоя(l), i−1), передаётся на вход функции модификатора для el(модификаторы слоя(l), i).
   Результат применения каждого модификатора, кроме последнего, передаётся на вход следующего модификатора в списке модификаторов слоя.

6. «Слой» –

   1. CлоЙ – обозначает непустое конечное множество названий слоёв – базовых структурных единиц канала, каждая из которых задаёт одну базовую текстуру, список её модификаций и способ объединения результата со значением, накопленным предыдущими слоями канала.

   2. Прозрачность слоя – обозначает функцию, сопоставляющую слою вещественное число от 0 до 1, определяющее долю участия результата слоя при его смешивании со значением, накопленным предыдущими слоями канала (0 – слой полностью прозрачен, 1 – слой непрозрачен).

   3. Базовая текстура слоя – обозначает функцию, сопоставляющую слою используемый им экземпляр базовой текстуры.

   4. Режим смешивания слоя – обозначает функцию, сопоставляющую слою используемый им режим смешивания, определяющий способ объединения результата слоя со значением, накопленным предыдущими слоями канала.

   5. Модификаторы слоя – обозначает функцию, сопоставляющую слою упорядоченный, возможно пустой, список модификаторов, которые применяются к результату базовой текстуры слоя последовательно, от первого к последнему; результат каждого следующего модификатора вычисляется на основе результата предыдущего.

   > (∀ l ∈ слои) (∃! C ∈ каналы) (∃ i ∈ I[1, length(слои канала(c))]) l = el(слои канала(c), i)
   Каждый слой принадлежит ровно одному каналу и притом ровно одной позиции в его упорядоченном списке слоёв.

7. «Канал» –

   1. Каналы – обозначает непустое конечное множество названий текстурных каналов; канал определяет одну из результирующих текстур материала.

   2. Слои канала – обозначает функцию, сопоставляющая каналу упорядоченную последовательность слоёв, которые вычисляются от первого к последнему, для получения итогового значения канала.

      >(∀ c ∈ каналы) (∀ i, j ∈ I[1, length(слои канала(c))]) i < j → el(слои канала(c),i) вычисляется раньше el(слои канала(c),j)
    Порядок слоёв в списке определяет порядок их вычисления и, соответственно, порядок смешивания слоёв канала.

8. «Материал» –

   1. Материал – обозначает непустое конечное множество названий процедурных материалов, создаваемых и настраиваемых пользователем в редакторе.

   2. Каналы материала – обозначает функцию, сопоставляющую материалу непустое множество текстурных каналов, из которых он состоит.
      >(∀ m ∈ материалы) (|каналы материала(m)| ∈ I[1,4])
      Материал состоит не менее чем из одного и не более чем из четырёх каналов по числу возможных типов результирующих текстур (albedo, normal, roughness, metallic).
      >(∀ m ∈ материалы) (∀ c1, c2 ∈ каналы материала(m)) (c1 ≠ c2)
      В пределах одного материала не может быть двух каналов с одинаковым названием.

   3. Базовые текстуры материала – обозначает функцию, сопоставляющую материалу непустое множество экземпляров базовых текстур, используемых хотя бы в одном слое хотя бы одного из его каналов.

9. «Шейдер и формирование изображения на экране»

   1. Шейдеры – обозначает непустое конечное множество шейдеров – программ на языке GLSL, полученных путём компиляции материалов и предназначенных для выполнения на графическом процессоре в процессе растеризации.

   2. Шейдер материала – обозначает функцию, сопоставляющую материалу шейдер, в который он компилируется. Каждому материалу соответствует ровно один шейдер.

   3. Растеризаторы – обозначает непустое конечное множество процессов растеризации; растеризатор преобразует геометрию поверхности 3D–модели в набор точек изображения, интерполируя параметризацию поверхности (UV–координаты) между вершинами примитива.

   4. Интерполированные координаты растеризатора – функция, сопоставляющая растеризатору множество интерполированных координат параметризации поверхности модели, вычисленных для точек, покрываемых текущим примитивом.

   5. Шейдер растеризатора – функция, сопоставляющая растеризатору используемый им шейдер; интерполированные координаты параметризации поверхности модели передаются этому шейдеру для вычисления цвета (отношение «координаты параметризации поверхности модели» на диаграмме).

   6. Точки – обозначает непустое конечное множество точек изображения (пикселей), для каждой из которых растеризатор с помощью шейдера вычисляет цвет.

   7. Координата x точки: точки → I[0, высота кадрового буфера)

   8. Координата y точки: точки → I[0, ширина кадрового буфера)

   9. Цвет точки: точки → цвет буфера

      >Термины «координата x», «координата y» и «цвет» точки обозначают соответственно горизонтальную и вертикальную позиции точки в кадровом буфере и вычисленный для неё цвет.

   10. Точки растеризатора – функция, сопоставляющая растеризатору непустое множество точек, для которых с помощью его шейдера вычисляется цвет (отношение «вычисляется цвет для» на диаграмме); цвет каждой такой точки определяется путём выполнения шейдера с координатами, интерполированными для этой точки.

   11. Кадровые буферы – обозначает непустое конечное множество кадровых буферов – прямоугольных областей памяти, хранящих цвет каждого пикселя итогового изображения.

   12. Высота кадрового буфера: кадровые буферы → I[1, 8192]

   13. Ширина кадрового буфера: кадровые буферы → I[1, 8192]

   14. Точки кадрового буфера – функция, сопоставляющая кадровому буферу множество точек, цвет которых он хранит (отношение «цвет каждого пикселя» на диаграмме).

       >(∀ f ∈ кадровые буферы) |точки кадрового буфера(f)| = ширина кадрового буфера(f) × высота кадрового буфера(f)
       Число точек кадрового буфера равно произведению его ширины на высоту – по одной точке на каждый пиксель.
       >(∀ f ∈ кадровые буферы) (∀ t ∈ точки кадрового буфера(f)) координата x точки(t) ∈ I[0, ширина кадрового буфера(f)) & координата y точки(t) ∈ I[0, высота кадрового буфера(f))
       Координаты точки не выходят за границы кадрового буфера, которому она принадлежит.

   15. Экраны – обозначает непустое конечное множество экранов – устройств вывода изображения.

   16. Высота экрана: экраны → I[1, 8192]

   17. Ширина экрана: экраны → I[1, 8192]

   18. Кадровый буфер экрана – функция, сопоставляющая экрану кадровый буфер, содержимое которого выводится на этот экран путём сканирования.

   >(∀ e ∈ экраны) ширина экрана(e) = ширина кадрового буфера(кадровый буфер экрана(e)) & высота экрана(e) = высота кадрового буфера(кадровый буфер экрана(e))
   Размер кадрового буфера, выводимого на экран, совпадает с разрешением этого экрана
